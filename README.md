# Simple Python Project Progress Tracker

This Python script simulates a basic project tracker, demonstrating fundamental programming concepts like lists, functions, loops, and user input. It helps a "new developer" track progress on initial tasks, reflecting the article's theme of building a solid foundation during "Dev Week 1" and adapting to new projects.

## Language

`python`

## How to Run

Save the code as `main.py`. Open a terminal or command prompt, navigate to the directory where you saved the file, and run it using `python main.py`. Follow the on-screen prompts to interact with the tracker.
